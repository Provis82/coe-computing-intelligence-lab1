# Telco Customer Churn Analysis

## Overview
This project explores a Telco Customer Churn dataset to uncover key demographics, service configurations, and payment methods associated with customer cancellations. 

## Tech Stack
* **Python**
* **Pandas** (Data preprocessing)
* **Matplotlib & Seaborn** (Data visualization)
* **Jupyter Notebook**
